# Aqua FM music bed credits

The station's background music is synthesized in-house — no third-party recordings, samples, or loops.

| Track | File | Length | Source | License |
|---|---|---|---|---|
| Aqua Drift | `public/music/aqua-drift.wav` | ~42 s | Composed and rendered by `scripts/make-music.mjs` (deterministic synth: pads, bass, bell arpeggio) | Original work of the Aqua Static team; cleared for use in this project |
| Static Tide | `public/music/static-tide.wav` | ~46 s | Same generator, different chord progression and tempo | Same |

To regenerate or add tracks, edit `scripts/make-music.mjs` and run `node scripts/make-music.mjs`.
